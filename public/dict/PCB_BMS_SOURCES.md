# PCB / PCBA 与 BMS 词库：来源与许可证

`PCB_T.json` 和 `BMS_T.json` 是面向工程工作场景的本地精选术语表。中文翻译与例句均由本项目编写；本项目没有复制下列资料中的定义、正文、图像或数据集内容。

## PCB / PCBA 术语参考

- [LibrePCB](https://librepcb.org/)（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）：元件、符号、封装、板层及制造输出的术语参考。
- [KiCad Documentation](https://docs.kicad.org/)（[CC BY 3.0 或更高版本](https://creativecommons.org/licenses/by/3.0/)；文档仓库的 [LICENSE](https://gitlab.com/kicad/services/kicad-doc/-/blob/master/LICENSE.adoc)）：原理图、PCB 编辑器、DRC 和制造流程术语参考。
- [Wikidata](https://www.wikidata.org/)（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）：公开实体名称与术语交叉核对。

## BMS / 电池工程术语参考

- [EMMO Battery](https://github.com/emmo-repo/domain-battery)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）：电化学、电池材料和测试概念的术语参考。
- [BattINFO](https://github.com/BIG-MAP/BattINFO)（[Apache License 2.0](https://github.com/BIG-MAP/BattINFO/blob/main/LICENSE)）：电池信息模型、测试和数据术语参考。
- [PyBaMM](https://github.com/pybamm-team/PyBaMM)（[BSD 3-Clause](https://github.com/pybamm-team/PyBaMM/blob/develop/LICENSE.txt)）：电池模型、电化学和验证术语参考。

这些来源仅用于术语核对与进一步学习。使用外部资料时，请分别遵守其许可证、署名要求和适用条款。
